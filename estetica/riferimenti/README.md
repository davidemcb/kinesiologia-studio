# Foto di riferimento per l'esame al tatto

Metti qui le foto che aiutano l'estetista a riconoscere ogni opzione dell'esame al tatto.
L'app le mostra da sola accanto all'opzione se il file si chiama `<prova>_<opzione>.jpg`,
con gli id presi da `../esame.json`. Esempi:

- `pizzicotto_solo_pizzicando.jpg`
- `noduli_macronoduli.jpg`
- `fovea_persistente.jpg`
- `tipo_pelle_disidratata.jpg`

Foto in formato JPEG, lato lungo 800 px circa, senza volti riconoscibili o con consenso scritto.
